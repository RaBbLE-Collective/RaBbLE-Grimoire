# RaBbLE/ — The Ethos Layer


The lore layer is where RaBbLE's philosophy, creation mythology, and visual world live. It is separate from the operational documentation in `RaBbLE-Agent/` — which tells agents *what to do* — because this layer tells the story of *why the entity exists and what it is*.

**If you're an agent starting a session:** Read `RaBbLE-Agent/RaBbLE-Identity.md` first. Come here when you need to understand the character at depth, write ethos-consistent content, or author new lore.

## Relationship to Operational Docs

The split is intentional and load-bearing:

- `RaBbLE-Agent/RaBbLE-Identity.md` — behavioral rules, format specs, state machine, system prompt. Agents read this. ~200 lines.
- `RaBbLE/Ethos/` — the philosophical substrate beneath those rules. Humans and deep-context agents read this.

Lore does not override operational docs. It explains them.
