## Track A — Aether as theming source of truth

### A1 — Naming unification (custom.css + userChrome.css)

Both `vscodium/assets/custom.css` and `firefox/userChrome.css` use `--aether-*` animation names that predate Aether's settled canonical naming. Rename to match what Aether's web CSS (`rabble-motion.css`) uses:

| Current name (non-canonical) | Canonical Aether name | Defined in |
|---|---|---|
| `--aether-angle` | `--harmony-angle` | `rabble-motion.css` (via `@property`) |
| `@keyframes aether-harmony-spin` | `@keyframes harmony-spin` | `rabble-motion.css` |
| `@keyframes aether-ring-glow` | harvest → `@keyframes rabble-ring-glow` | doesn't exist yet — **Track A3** |
| `@keyframes aether-glow-cycle` | harvest → `@keyframes rabble-glow-cycle` | doesn't exist yet — **Track A3** |
| `@keyframes aether-flow-x` | `@keyframes harmony-scroll` | `rabble-motion.css` (already exists) |

**Files to edit:** `themes/vscodium/assets/custom.css`, `themes/firefox/userChrome.css`.

**Self-contained constraint:** Both files are injected verbatim into host apps where `@import` is blocked (Electron's `vscode-file://` scheme; XUL's security model). Keyframes must remain inline in each file. After renaming they match Aether canonical names, but they still need to be inline duplicates. Add a comment:

```css
/* Keyframe names match Aether motion (rabble-motion.css / harmony-spin, harmony-scroll).
 * Defined inline: @import is blocked in this injection context.
 * Edit source at RaBbLE-Aether/themes/vscodium/assets/custom.css — not the injected copy. */
```

After rename, re-run Ansible (`--tags vscode` or `--tags browsers`) to push the updated files to the live system.

### A2 — Firefox off-palette hex audit

`firefox/userChrome.css` contains 3 hex values not in the canonical 13-color palette:

| Hex | Appears to be | Recommended replacement |
|---|---|---|
| `#3d3860` | mid-purple between border/muted — likely a tinted border hover state | `color-mix(in srgb, var(--rabble-border) 60%, var(--rabble-muted) 40%)` or `rgba(42,40,64,0.70)` |
| `#9e9ab8` | light muted purple — likely inactive/placeholder text | Replace with `var(--rabble-muted)` (#6b6880) or `#6b6880cc` |
| `#c4c0d8` | near-text off-white — likely a dimmed text state | Replace with `var(--rabble-text)` (#e8e6f0) at reduced opacity |

**Action:** Read each usage in context, determine the semantic intent, replace with the nearest palette value (or alpha variant thereof). After this, `userChrome.css` passes the same QA gate as Kvantum: every hex is a subset of the 13 Aether palette hexes.

### A3 — VSCodium JSON palette pipeline

The 931-line `RaBbLE-Aether-color-theme.json` has hardcoded hex values and alpha variants (`#ff2d7820`, `#00f5ff40`, etc.). The Kvantum pipeline is the model.

**Approach:** Create `themes/_palette/gen-vscodium-theme.sh` — analogous to `recolor.sh`.

The script reads a palette map (`themes/_palette/aether-vscodium.map` or directly from `group_vars/all.yml`) and regenerates `themes/vscodium/themes/RaBbLE-Aether-color-theme.json` from a template.

**Implementation options (choose one):**

**Option 1 — Shell + sed (matches Kvantum pattern exactly):**
- Create `themes/vscodium/themes/RaBbLE-Aether-color-theme.json` as the template with canonical hex values (it already is — just add a header comment flagging it as generated)
- `gen-vscodium-theme.sh` runs a sed pass that replaces the 13 canonical hexes from `group_vars/all.yml`
- QA gate: every hex in the output is a subset of the current palette

**Option 2 — Jinja2 template (Ansible-native):**
- Rename the JSON to `RaBbLE-Aether-color-theme.json.j2`, replace every palette hex with `{{ rabble_palette.magenta }}` etc.
- Add a `template:` task to `vscode.yml` that renders the `.j2` → `.json` before copying
- Alpha variants: encode as `{{ rabble_palette.magenta }}20` (JSON supports 8-char hex)

**Recommendation:** Option 2 (Jinja2) — it's the simpler implementation and Ansible already does the deployment step anyway. The template lives in Aether, Ansible renders it during deploy. A palette change in `group_vars/all.yml` propagates automatically on the next `layerctl apply`.

**QA gate (same as Kvantum):** Every `#rrggbb` in the rendered JSON must be a subset of the 13 Aether palette hexes. Alpha variants (`#rrggbbaa`) are allowed.

### A4 — Harvest CSS patterns into Aether web CSS

Two keyframes in `custom.css` / `userChrome.css` are valuable for web contexts and don't exist in Aether yet. Extract to `RaBbLE-Aether/assets/motion/rabble-motion.css`:

**`rabble-glow-cycle`** — cycling box-shadow through cyan → violet → magenta over 9s. Applies to any element that should pulse with the full palette (popups, highlights, active zones).

```css
@keyframes rabble-glow-cycle {
  0%   { box-shadow: 0 0 12px color-mix(in srgb, var(--rabble-cyan)    35%, transparent),
                     0 0 24px color-mix(in srgb, var(--rabble-cyan)    12%, transparent); }
  33%  { box-shadow: 0 0 12px color-mix(in srgb, var(--rabble-violet)  35%, transparent),
                     0 0 24px color-mix(in srgb, var(--rabble-violet)  12%, transparent); }
  66%  { box-shadow: 0 0 12px color-mix(in srgb, var(--rabble-magenta) 35%, transparent),
                     0 0 24px color-mix(in srgb, var(--rabble-magenta) 12%, transparent); }
  100% { box-shadow: 0 0 12px color-mix(in srgb, var(--rabble-cyan)    35%, transparent),
                     0 0 24px color-mix(in srgb, var(--rabble-cyan)    12%, transparent); }
}
```

**`rabble-ring-glow`** — same cycle at 14px spread; used on the ring's outer blur. Consider whether this merges into `rabble-glow-cycle` via a `--rabble-glow-spread` custom property rather than two separate keyframes.

**`.rabble-scrollbar-neon`** — add to `rabble-components.css` base section. Glowing magenta scrollbar thumb (from `custom.css`), palette-var-clean:

```css
.rabble-scrollbar-neon::-webkit-scrollbar       { width: 6px; height: 6px; }
.rabble-scrollbar-neon::-webkit-scrollbar-thumb {
  background: var(--rabble-magenta);
  border-radius: 9999px;
  box-shadow: 0 0 6px var(--rabble-magenta);
}
.rabble-scrollbar-neon::-webkit-scrollbar-thumb:hover {
  background: var(--rabble-pink);
  box-shadow: 0 0 10px var(--rabble-pink);
}
.rabble-scrollbar-neon::-webkit-scrollbar-track { background: var(--rabble-void); }
```

The existing Aether scrollbar (4px, muted border color) stays as the default minimal style. `.rabble-scrollbar-neon` is the decorative opt-in.

### B1 — `.rabble-glitch-veil` (chromatic stutter wash)

**Source:** `RaBbLE-liminal.css:420–438`

A `linear-gradient(105deg, magenta→transparent→cyan)` overlay at `mix-blend-mode: screen`, toggled with body-class `.is-glitching`. `opacity` + `translateX` jitter via `veil-stutter 0.42s steps(2)`.

**Target:** `rabble-components.css` as `.rabble-glitch-veil`. Host must be `position: relative`. Body class `.is-glitching` activates.

### B2 — `.rabble-glitch-text` (RGB-split text)

**Source:** `RaBbLE-liminal.css:440–446`

`text-shadow: ±3px cyan / ∓3px magenta + 60px violet bloom`, `0.18s steps(2)`. Applied to text elements.

**Target:** `rabble-components.css` as `.rabble-glitch-text`. Document knobs in Theme-System: split distance (3px), bloom radius (60px), step duration (0.18s).

Pairs with `.rabble-glitch-veil` on the parent container.

### B3 — `.rabble-breathe` (sigil pulse consolidation)

Two near-identical implementations exist and should collapse to one:
- `RaBbLE-World/world/css/RaBbLE-dock.css:64` — `.rd2-sigil-pulse`
- `RaBbLE-Chrysalis/.../css/RaBbLE-liminal.css:100–103` — `lsb-breathe`

**Target:** `rabble-components.css` as `.rabble-breathe` with `--rabble-breathe-color` (default `var(--rabble-green)`) and `--rabble-breathe-period` (default 3s) knobs. Replace both source usages when pages are rebuilt.

### B4 — Summoning ring speed states (NeBuLA)

**Source:** `RaBbLE-Chrysalis/.../css/RaBbLE-Grimoire.css:339–378`

Three-state ring choreography: rest / summoning / summoned — each with different CW/CCW rotation speeds for outer ring, inner ring, and rune layer.

**Target:** `RaBbLE-NeBuLA/src/ui/grimoire-ring.js` — expose `setState(state)` method that toggles CSS classes (`.is-summoning`, `.is-summoned`) on the ring element. Companion CSS classes go in `rabble-components.css` or the NeBuLA element's shadow CSS.

This is a NeBuLA change, not just Aether CSS. Coordinate with NeBuLA.

1. Update `RaBbLE-OS/ansible/inventory/group_vars/all.yml` (palette vars block)
