## Proposal

1. **One spec** `RaBbLE-Agent/RaBbLE-Brand-Mark-Spec.md`: portal geometry, offset rule, eye rule, the size ladder (full / compact / micro / glyph), palette roles. Absorbs `rabble-portal-glyphs-spec.md`; Aether keeps a pointer.
2. **One source per kind**, others derived:
   - vector master: `RaBbLE-Aether/assets/logos/` (SVG, CDN-served)
   - cell master: `rabble-face` (Rust); export an ANSI/text snapshot per size via the existing `show` example
   - fastfetch reads the exported snapshots instead of hand-drawn art (full keeps its fx layers)
3. **Delete duplicates by pointer** (condense, not delete): `RaBbLE.svg` copies, `RaBbLE_ascii.txt`/`RaBbLE.ansi` generators in OS/assets.
4. **Size ladder as a contract:** each surface picks a rung by available space (fastfetch now does: `spells/rabble-fetch`, <82 cols or <30 rows drops to compact, <44 cols or <12 rows to no logo).
